# Política de segurança

Se você identificou uma possível vulnerabilidade no I.See Enterprise, **não abra uma issue pública**.

Envie um relato privado pelo recurso **"Report a vulnerability"** (GitHub Security Advisories)
deste repositório, incluindo:

- descrição do problema e impacto;
- passos para reproduzir;
- versão afetada, se conhecida.

Responderemos o mais breve possível e coordenaremos a divulgação após a correção.

Este repositório não contém código-fonte do produto, credenciais nem dados pessoais.
